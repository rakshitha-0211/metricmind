# MetricMind

## Agentic Semantic BI Engine

MetricMind is an AI-powered conversational Business Intelligence application.

Users can ask business questions in natural language and receive:

- Business metrics
- Data-driven answers
- Root-cause analysis
- Visualizations
- SQL transparency

- Snowflake
- dbt
- Cube.dev
- LangChain
- Next.js
